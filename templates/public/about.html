Advanced Database Management Systems (ADBMS) Project

System Architecture & MongoDB NoSQL Showcase

This project demonstrates the core theoretical and practical principles of modern NoSQL distributed database systems using MongoDB and PyMongo.

1. Document Model: Embedding vs. Referencing

Normalized References (`ObjectId`): Used for `users`, `events`, `venues`, and `registrations` to maintain independent entity lifecycles and avoid the 16MB document size limit.

Embedded Subdocuments: Used for event budget breakdowns and organizer feedback responses to ensure atomic single-document read locality without extra joins.

2. Concurrency & Atomicity (Zero Overbooking)

Demonstrates MongoDB atomic conditional operations using find_one_and_update.

When students register concurrently, the query filter { registered_count: { $lt: capacity } } and atomic update { $inc: { registered_count: 1 } } guarantees that race conditions never allow capacity to exceed venue limits.

3. Indexing Strategies & Query Optimization

Unique Indexes: Enforces uniqueness on users.email, venues.code, and registrations.ticket_code.

Compound Indexes: { organizer_id: 1, start_time: 1 } and { status: 1, start_time: 1 } accelerate multi-key queries and sorting without in-memory sort penalties.

4. Aggregation Pipeline Framework

Implements multi-stage aggregation pipelines across analytics dashboards:
$match → $lookup → $unwind → $group → $project → $facet.

Computes real-time attendance percentages, category popularity, and venue utilization.

MongoDB Collections Summary

Collection Primary Key / Foreign Keys Indexes Description
users _id Unique on email User accounts, role (admin/organizer/student), hashed password.
events _id, Ref: organizer_id, venue_id Compound on (organizer_id, start_time) Event details, schedule, capacity counter, budget breakdown.
registrations _id, Ref: event_id, student_id Unique on ticket_code, Compound on (event_id, student_id) Attendance state (registered, waitlisted, checked-in, cancelled).
venues _id Unique on name and code Auditoriums and seminar halls with facility arrays.
feedback _id, Ref: event_id, student_id Unique compound on (event_id, student_id) Attendee reviews with keyword sentiment scoring demo.
notifications _id, Ref: user_id Index on (user_id, created_at DESC) In-app notifications for tickets, reminders, waitlists.
audit_logs _id, Ref: actor_id Index on timestamp DESC Security audit trail capturing administrative operations.
